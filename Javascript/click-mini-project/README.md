## Project Overview

This project is a simple shopping list web app built with JavaScript. It tracks:
- The number of times each shopping list item is clicked.
- The number of times a user adds a new item to the list.

## Features

- Add new items to the shopping list.
- Click on items to increment their click count.
- Display the click count for each item.
- Track and display the total number of items added.

## Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.
3. Start adding and clicking items!

## Example Usage

```javascript
// Add item
addItem('Apples');

// Click item
itemClicked('Apples');
```
